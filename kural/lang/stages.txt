# The core of kural's program language: pipeline stages. Read by kural/ir.py and by the Rust code.
#
#   % kind value value ...          a set of fixed values (an "enum")
#   & list name name ...            a named list of stages
#   @ name SRC DST slot slot ...    a stage: SRC is the data type it takes ("-" = starts a pipeline), DST what it gives
#                                   slot "name:type" copies words (type says how they are read), "name:type?" may be left out,
#                                   slot "name=kind" is one value of the enum "kind"
#   *commands                       the stand-alone commands of commands.txt go here, in their order
#
# Data types: files, lines, procs, done (the pipeline has ended), neg (after "not"), sudo (after "sudo").
# The order of stages fixes the model's token numbers: append new stages, never reorder, or retrain.
