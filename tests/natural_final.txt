# ---- files
list all rust files in ~/code/engine => files what=anyfile in=~/code/engine | ext ext=rust | fshow
show the 3 newest files in /var/log => files what=anyfile in=/var/log | fsort key=time order=desc | ftake n=3 | fshow
find files larger than 300MB under /opt => files what=anyfile in=/opt | larger size=300MB | fshow
which folders in ~/dev are empty => files what=dirs in=~/dev | empty | fshow
files containing "BEGIN RSA" in ~/.ssh => files what=anyfile in=~/.ssh | contains text=[BEGIN RSA] | fshow
show sql files older than 1 year in backups => files what=anyfile in=backups | ext ext=sql | older age=[1 year] | fshow
find anything named Thumbs.db on /mnt/usb => files what=anyfile in=/mnt/usb | name mode=is text=Thumbs.db | fshow
list png files with icon in the name in assets => files what=anyfile in=assets | ext ext=png | name mode=has text=icon | fshow
what are the ten biggest files in ~/Videos => files what=anyfile in=~/Videos | fsort key=size order=desc | ftake n=ten | fshow
show me everything modified in the last 30 minutes => files what=anyfile | newer age=[30 minutes] | fshow
count the mp3 files in ~/Music => files what=anyfile in=~/Music | ext ext=mp3 | fcount
how many files in /etc are smaller than 1kb => files what=anyfile in=/etc | smaller size=1kb | fcount
delete all .DS_Store files under ~/Projects => files what=anyfile in=~/Projects | ext ext=.DS_Store | delete
remove empty directories in /var/tmp => files what=dirs in=/var/tmp | empty | delete
move all docx files from desktop to documents => files what=anyfile in=desktop | ext ext=docx | move to=documents
copy the newest 5 files from ~/Downloads to ~/keep => files what=anyfile in=~/Downloads | fsort key=time order=desc | ftake n=5 | copy to=~/keep
compress all csv files in exports into exports.zip => files what=anyfile in=exports | ext ext=csv | compress fmt=zip to=exports.zip
total size of files older than 6 months in ~/Downloads => files what=anyfile in=~/Downloads | older age=[6 months] | total
how big is each folder in /usr => files what=dirs in=/usr | sizes
delete the oldest 20 files in ~/.cache/thumbnails => files what=anyfile in=~/.cache/thumbnails | fsort key=time order=asc | ftake n=20 | delete
get rid of all tmp files bigger than 10 megs in /tmp => files what=anyfile in=/tmp | ext ext=tmp | larger size=[10 megs] | delete
archive everything in reports modified this year into reports-2026.tar.gz => files what=anyfile in=reports | newer age=[this year] | compress fmt=tgz to=reports-2026.tar.gz
find the smallest file in logs => files what=anyfile in=logs | fsort key=size order=asc | ftake | fshow
list directories starting with test in src => files what=dirs in=src | name mode=starts text=test | fshow

count lines with "status=500" in api.log => lines of=api.log | match text=status=500 | lcount
sort users.csv and remove duplicates => lines of=users.csv | lsort key=alpha order=asc | uniq | lshow
grep TODO in main.go => lines of=main.go | match text=TODO | lshow
save lines containing error from server.log to errors.log => lines of=server.log | match text=error | save to=errors.log
show the beginning of notes.md => lines of=notes.md | ltake | lshow
