# Hand-written requests (not produced by the generator) with the program they should parse to.
# Format:  request  =>  stage key=value ... | stage ...  ;;  next pipeline
# A value with spaces goes in [brackets]. Scoring compares the compiled command, so harmless
# differences in which exact words were copied (e.g. "downloads" vs "my downloads") still count as right.
